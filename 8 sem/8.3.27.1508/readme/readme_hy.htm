Ուսումնական տարբերակ

"1С:Ձեռնարկություն 8.3" հարթակի ուսումնական տարբերակ -"1С:Ձեռնարկություն 8.3" իրական գործող հարթակ հետևյալ սահմանափակումներով`

  • սահմանափակվել է տվյալների քանակը`
    • գրառումների առավելագույն քանակ հաշիվների աղյուսակներում 500
    • գրառումների առավելագույն քանակ օբյեկտների գլխավոր աղյուսակներում 200
    • գրառումների քանակ օբյեկտների աղյուսակային մասերում 1000
    • գրառումների քանակ գրառումների հավաքածուներում 1000
    • տվյալների արտաքին աղբյուրների գրառումների քանակ 200
  • չի ապահովվում աշխատանքը հաճախորդ-սերվեր տարբերակում;
  • չի ապահովվում բաշխված տեղեկատվական բազաների աշխատանքը;
  • չի ապահովվում COM-միացում;
  • բացակայում է գաղտնաբառերի օգտագործման և օգտագործողների համար օպերացիոն համակարգի վավերացման հնարավորությունը;
  • աղյուսակային փաստաթղթերի տպագրումը և պահպանումը ապահովվում է միայն Կոնֆիգուրատորի ռեժիմում;
  • չի ապահովվում մեկից ավելի բջիջ պարունակող աղյուսակային փաստաթղթերը 1С:Ձեռնարկություն ռեժիմում;
  • ուսումնական տարբերակի արագ գործողությունը ավելի ցածր է, քան "1С:Ձեռնարկություն 8.3" առևտրային տարբերակում;
  • չի ապահովվում աշխատանքը կոնֆիգուրատորի պահոցի հետ;
  • անհասանելի է կոնֆիգուրացիայի տեղադրման հետ կապված ֆունկցիոնալությունը;
  • տեղեկատվական բազայի հետ աշխատանքի միաժամանակ սեանցների քանակը սահմանափակված է մեկ սեանսով:
  • բաժանիչների արժեքները տրվում են արժեքներով լռությամբ տվյալ տիպի բաժանիչի համար:
