1C:Enterprise 8.3

Versione di apprendimento

Versione di apprendimento della piattaforma "1С:Enterprise 8.3" - piattaforma funzionante realmente "1С: Enterprise 8.3" con le seguenti limitazioni:

  • numero di dati limitato;
    • massimo numero di registrazioni nelle tabelle degli account 500;
    • numero massimo di registrazioni nelle tabelle principali degli oggetti 200;
    • numero di registrazioni nelle parti tabellari degli oggetti 1000;
    • numero di registrazioni nei set di registrazioni 1000;
    • numero di registrazione dei sorgenti esterni di dati 200;
  • non è supportato il lavoro nella variante client-server;
  • non è supportato il lavoro dei database distribuiti;
  • non è supportato il collegamento COM
  • non è possibile utilizzare password e autenticazione del sistema operativo per gli utenti;
  • la stampa e il salvataggio di documenti tabellari sono supportati solo in modalità Configuratore;
  • la copia del contenuto di più di una cella di un documento tabellare in modalità 1C: Enterprises non è supportata;
  • le prestazioni della versione di apprendimento è inferiore a quella della versione commerciale di "1C: Enterprise 8.3";
  • il lavoro con il repository di configurazione non è supportato;
  • la funzionalità associata alla consegna della configurazione non è disponibile;
  • il numero di sessioni simultanee con il database è limitato a una sessione.
  • i valori del separatore sono impostati di default per questo tipo di separatore.

La versione di apprendimento non ha alcuna protezione hardware o software.

Basato sulla versione di apprendimento della piattaforma 1C: Enterprise 8.3, 1C ha lanciato il prodotto 1C: Enterprise 8.3. Versione di apprendimento del programma". Questo prodotto è destinato alla formazione degli utenti e non può essere utilizzato per risolvere problemi reali nell'automazione aziendale.

Prodotto software "1C: Enterprise 8.3. La versione di apprendimento in programmazione è "progettata per ottenere le capacità di modificare esistenti e creare nuove soluzioni applicative nel sistema 1C: Enterprise 8.3".

Ulteriori informazioni su questo prodotto software sono disponibili su www.v8c.ru/edu del sito di sistema "1С:Enterprise 8".
