1C:Enterprise 8.3

Versão de treinamento

A versão de treinamento da plataforma 1C:Enterprise 8.3 é uma plataforma funcional do 1C:Enterprise 8.3 mas com as seguintes restrições:

  • quantidade limitada de dados:
    • o número máximo de registros em tabelas de faturas é de 500;
    • o número máximo de registros em tabelas principais dos objetos é de 200;
    • o número de registros em tabelas dos objetos é de 1.000;
    • o número de registros em conjuntos de registros é de 1.000;
    • o número de registros de fontes externas de dados é de 200;
  • o trabalho no modo cliente-servidor não é suportado;
  • o trabalho de bases de informações distribuídas não é suportado;
  • a conexão COM (Modelo de Objeto de Componente) não é suportada;
  • não há possibilidade de usar senhas e autenticação do sistema operacional para usuários;
  • a impressão e gravação de documentos de planilha são suportadas apenas no modo de Designer;
  • a cópia de conteúdo de mais de uma célula do documento de planilha no modo de 1C:Enterprise não é suportada;
  • o desempenho da versão de treinamento é inferior ao da versão comercial de 1C:Enterprise 8.3;
  • o trabalho com o repositório de configuração não é suportado;
  • a funcionalidade relacionada à distribuição de configuração está indisponível;
  • o número de sessões simultâneas de trabalho com a base de informações é limitado a uma sessão.
  • os valores de separadores são definidos com os valores padrão para este tipo de separador.

A versão de treinamento não tem nenhuma proteção de hardware ou software.

A empresa 1C lançou seu produto 1C:Enterprise 8.3 com base na versão de treinamento da plataforma 1C:Enterprise 8.3. Versão para aprendizado de programação. Este produto é projetado para ensinar usuários e não pode ser usado para resolver problemas reais de automatização empresarial.

Produto de software 1C:Enterprise 8.3. A versão para aprendizado de programação é projetada para adquirir habilidades de modificação das soluções de aplicação existentes e criar novas no sistema 1C:Enterprise 8.3.

Veja informações mais detalhadas sobre este produto de software  na seção www.v8c.ru/edu no site do sistema 1C:Enterprise 8.
